# مذكّرتي — خدمة التنبيهات الخلفية

Cloudflare Worker صغير يرسل تنبيهات Web Push للمهام حتى لو تطبيق مذكّرتي
مقفول تمامًا على الجهاز. مجاني بالكامل (الفئة المجانية من Cloudflare Workers
تكفي بسهولة لاستخدام شخصي).

**منشور على:** `https://mudhakkirah-push.k12345aled.workers.dev`

## كيف يعمل

1. عند تفعيل "تنبيهات المهام" من إعدادات التطبيق، يشترك المتصفح في Web Push
   ويُرسِل التطبيق قائمة تذكيراته (مع أوقات إطلاق محسوبة مسبقًا) إلى `/sync`.
2. الخادم يخزّنها في Workers KV تحت رمز جهاز عشوائي (`deviceToken`).
3. مُشغّل (cron) يعمل كل دقيقة، يفحص كل الأجهزة المخزَّنة، ويرسل أي تنبيه
   حان وقته عبر Web Push (تشفير RFC 8291 عبر مكتبة `web-push`، وتوقيع VAPID).
4. الـ service worker في التطبيق (`sw.js`) يستقبل التنبيه ويعرضه — حتى لو
   المتصفح/التطبيق مغلق تمامًا (يعمل ما دام المتصفح نفسه مثبّتًا على الجهاز
   ومتصلًا بالإنترنت من وقت لآخر).

## الأمان

لا يوجد نظام تسجيل دخول — الحماية الوحيدة هي أن `deviceToken` رقم عشوائي طويل
(UUID، ١٢٢ بت) يُنشأ في المتصفح ولا يمكن تخمينه، وCORS مقصور على أصل الموقع
(`https://rkcyyd.github.io`) فقط. هذا مناسب لاستخدام شخصي لكنه ليس نظام
مصادقة حقيقيًا — أي شخص يحصل على `deviceToken` تحديدًا يقدر يقرأ/يعدّل بيانات
ذلك الجهاز فقط (لا غيره)، ومفتاح VAPID الخاص محفوظ كسرّ في Cloudflare
(`wrangler secret`) ولا يظهر في الشيفرة المصدرية أبدًا.

## التطوير محليًا

```bash
cd server
npm install
export CLOUDFLARE_API_TOKEN=...   # توكن Workers من dash.cloudflare.com/profile/api-tokens
npx wrangler dev                  # تشغيل محلي
npx wrangler deploy               # نشر
```

### الأسرار (لا تُكتب في wrangler.toml)

```bash
npx wrangler secret put VAPID_PRIVATE_KEY
```

مفتاح VAPID العام (يظهر في كود العميل، ليس سرًا) موجود في `wrangler.toml`
تحت `[vars]`، ويقابله في `js/push-sync.js` (`VAPID_PUBLIC_KEY`) — يجب أن
يتطابقا دائمًا.

## نقاط النهاية (Endpoints)

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/health` | GET | فحص أن الخدمة تعمل |
| `/sync` | POST | حفظ/تحديث اشتراك الجهاز وتذكيراته |
| `/sync` | DELETE | حذف بيانات جهاز (عند إيقاف التنبيهات) |
| `/test-push` | POST | إرسال تنبيه تجريبي فوري لجهاز معيّن |
| `/run-now` | POST | تشغيل فحص المواعيد يدويًا (بدل انتظار الـ cron) |
