# مذكّرتي 🗓️

تطبيق ويب بسيط: **تقويم هجري + ميلادي** مع **جدول مهام** و**ملاحظات شخصية** و**ويدجت سطح مكتب**.
مبني بدون أي إطار عمل ولا خطوة بناء (HTML/CSS/JavaScript صِرف) ليسهُل تعديله وتوسيعه.

## المزايا الحالية

- تقويم شهري يعرض التاريخ **الهجري (أم القرى)** و**الميلادي** واليوم من الأسبوع.
- إضافة مهام لأي يوم، وتمييزها بالإنجاز.
- أنواع المهام قابلة للإدارة بالكامل من صفحة **أنواع المهام**:
  - **واجب**
  - **اختبار**: ثلاثة أشكال بألوان مميزة — **ميد** (برتقالي)، **كويز** (أخضر)، **فاينل** (أحمر).
  - **شخصي**: مع زر لإخفائه من التقويم.
  - إضافة أنواع جديدة بألوان مخصّصة.
- **عدّاد تنازلي لأقرب اختبار** أعلى التقويم والويدجت (يُفعّل/يُطفأ من الإعدادات).
- **ملاحظات شخصية**: مساحة نصية حرة بحفظ تلقائي.
- **ويدجت سطح المكتب** (`#/widget`): نافذة صغيرة تعرض المتأخر + اليوم + الأسبوع القادم،
  قابلة للتحكم (إنجاز، إضافة، فتح التطبيق كاملًا).
- وضع ليلي، وبداية أسبوع قابلة للضبط.
- **تصدير/استيراد** نسخة من البيانات (JSON) لنقلها بين الأجهزة.
- يعمل بلا إنترنت وقابل للتثبيت على الجوال (PWA).

## التخزين

البيانات محفوظة **محليًا في المتصفح** (`localStorage`). كل القراءة/الكتابة تمر عبر
[`js/store.js`](js/store.js) — عند إضافة مزامنة سحابية لاحقًا (Supabase/Firebase) نغيّر
قسم `adapter` هناك فقط، دون لمس بقية التطبيق.

## التشغيل محليًا

يحتاج خادمًا محليًا بسيطًا (بسبب وحدات ES):

```bash
python serve.py 5173
```

ثم افتح <http://localhost:5173>. (خادم تطوير: يمنع التخزين المؤقت، ولا يُنشر.)

## سطح المكتب (ويندوز)

```powershell
powershell -ExecutionPolicy Bypass -File desktop\install-shortcuts.ps1
```

ينشئ أيقونة **مذكّرتي** على سطح المكتب، وويدجت في **بدء التشغيل** يفتح تلقائيًا عند
تسجيل الدخول. التفاصيل في [`desktop/README.md`](desktop/README.md).

## النشر (استضافة مجانية)

الموقع **ثابت** بالكامل ويعمل على أي استضافة ثابتة. المسارات كلها نسبية فيعمل من مجلد فرعي.

### GitHub Pages (موصى به — مجاني بالكامل)

```bash
git remote add origin https://github.com/USERNAME/mudhakkirah.git
git push -u origin main
```

ثم في المستودع: **Settings → Pages → Source: GitHub Actions** (يوجد workflow جاهز في
`.github/workflows/deploy.yml`)، أو **Deploy from a branch → main → / (root)**.
الرابط: `https://USERNAME.github.io/mudhakkirah/`.

### بدائل

- **Netlify**: اسحب المجلد إلى <https://app.netlify.com/drop> → رابط `xxx.netlify.app`.
- **Vercel**: New Project → Other → Deploy (ملف `vercel.json` جاهز).

بعد النشر: حدّث `APP_URL` في `desktop/mudhakkirah.vbs` إلى رابط موقعك حتى يعمل الويدجت
بلا خادم محلي.

## بنية الملفات

```
index.html               الهيكل والقائمة
css/styles.css            كل الأنماط (متغيّرات CSS للألوان والثيم)
js/
  app.js                 التوجيه، القائمة، الثيم، تسجيل PWA
  store.js               طبقة البيانات + nextExam()  ← نقطة تبديل المزامنة لاحقًا
  dates.js               أدوات التاريخ الهجري/الميلادي (Intl فقط)
  dom.js                 أدوات بناء عناصر + نافذة منبثقة
  taskform.js            نموذج إضافة/تعديل مهمة
  examcountdown.js       لافتة العدّاد التنازلي لأقرب اختبار
  views/
    calendar.js          التقويم
    tasks.js             قائمة المهام والفلاتر
    types.js             إدارة أنواع المهام
    notes.js             الملاحظات الشخصية
    widget.js            واجهة سطح المكتب المصغّرة
    settings.js          الإعدادات والاستيراد/التصدير
assets/fonts/            خط ثمانية (self-hosted)
assets/icon.{svg,png,ico} الأيقونة
desktop/                 مشغّلات ويندوز (أيقونة + ويدجت + توليد أيقونة)
serve.py                 خادم تطوير محلي
sw.js                    service worker للعمل بلا إنترنت
.github/workflows/       نشر تلقائي على GitHub Pages
```

## أفكار للإضافات القادمة (متفق عليها)

- عرض أسبوعي وقائمة "الأسبوع القادم".
- تذكيرات/إشعارات (بعد تثبيت PWA).
- تكرار المهام (كل أسبوع مثلًا).
- بحث في المهام والملاحظات.
- مفتاح ألوان أسفل التقويم.
- سحب المهمة بين الأيام في التقويم لتغيير تاريخها.
- مزامنة سحابية + تسجيل دخول.
