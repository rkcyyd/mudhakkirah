# مذكّرتي 🗓️

تطبيق ويب بسيط: **تقويم هجري + ميلادي** مع **جدول مهام** و**ملاحظات شخصية**.
مبني بدون أي إطار عمل ولا خطوة بناء (HTML/CSS/JavaScript صِرف) ليسهُل تعديله وتوسيعه.

## المزايا الحالية

- تقويم شهري يعرض التاريخ **الهجري (أم القرى)** و**الميلادي** واليوم من الأسبوع.
- إضافة مهام لأي يوم، وتمييزها بالإنجاز.
- أنواع المهام قابلة للإدارة بالكامل من صفحة **أنواع المهام**:
  - **واجب**
  - **اختبار**: ثلاثة أشكال بألوان مميزة — **ميد** (برتقالي)، **كويز** (أخضر)، **فاينل** (أحمر).
  - **شخصي**: مع زر لإخفائه من التقويم.
  - إضافة أنواع جديدة بألوان مخصّصة.
- **ملاحظات شخصية**: مساحة نصية حرة بحفظ تلقائي.
- وضع ليلي، وبداية أسبوع قابلة للضبط.
- **تصدير/استيراد** نسخة من البيانات (JSON) لنقلها بين الأجهزة.
- يعمل بلا إنترنت وقابل للتثبيت على الجوال (PWA).

## التخزين

حاليًا البيانات محفوظة **محليًا في المتصفح** (`localStorage`). كل القراءة/الكتابة تمر عبر
[`js/store.js`](js/store.js) — عند إضافة مزامنة سحابية لاحقًا (Supabase مثلًا) نغيّر
قسم `adapter` هناك فقط.

## التشغيل محليًا

يحتاج خادمًا محليًا بسيطًا (بسبب وحدات ES). من داخل مجلد `mudhakkirah`:

```bash
python serve.py 5173
```

ثم افتح <http://localhost:5173>. (خادم التطوير هذا يمنع التخزين المؤقت حتى تظهر
تعديلاتك فورًا؛ لا تستخدمه للنشر.)

## النشر (استضافة)

الموقع **ثابت** بالكامل، يعمل على أي استضافة ثابتة. الموصى به **Vercel**:

1. ارفع المجلد إلى مستودع GitHub.
2. في Vercel: New Project → اختر المستودع → Framework Preset: **Other** → Deploy.
3. لا يحتاج أي إعداد؛ ملف `vercel.json` جاهز.

بدائل: Netlify (اسحب المجلد إلى netlify.com/drop)، أو GitHub Pages.

## بنية الملفات

```
index.html              الهيكل والقائمة
css/styles.css           كل الأنماط (متغيّرات CSS للألوان والثيم)
js/
  app.js                 التوجيه، القائمة، الثيم، تسجيل PWA
  store.js               طبقة البيانات (localStorage الآن)
  dates.js               أدوات التاريخ الهجري/الميلادي (Intl فقط)
  dom.js                 أدوات بناء عناصر + نافذة منبثقة
  taskform.js            نموذج إضافة/تعديل مهمة
  views/
    calendar.js          التقويم
    tasks.js             قائمة المهام والفلاتر
    types.js             إدارة أنواع المهام
    notes.js             الملاحظات الشخصية
    settings.js          الإعدادات والاستيراد/التصدير
assets/fonts/            خط ثمانية (self-hosted)
sw.js                    service worker للعمل بلا إنترنت
```

## أفكار للإضافات القادمة

- مزامنة سحابية + تسجيل دخول (Supabase).
- عرض أسبوعي وعرض قائمة "الأسبوع القادم".
- تذكيرات/إشعارات.
- ربط المهام بمواد دراسية (اسم المادة، الأستاذ).
- تكرار المهام (كل أسبوع مثلًا).
- سحب وإفلات المهام بين الأيام.
